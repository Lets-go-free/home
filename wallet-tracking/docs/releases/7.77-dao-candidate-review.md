## Implementiert
- Einheitliche sichtbare Version 7.77 und Build-ID in `index.html`.
- Neuer Status `needs_review` für nicht eindeutig widerlegte NFT-Besitznachweise.
- Bestehende `unverified`-Kandidaten mit unklaren Gründen werden per Migration in `needs_review` überführt. Ein eindeutiger Nachweis `owned-by-other-wallet` bleibt `unverified`.

## Installation
1. ZIP in das Repo einspielen.
2. SQL-Migration aus `supabase/migrations/` ausführen.
3. Webdateien veröffentlichen und Version 7.77 prüfen.
4. `dao-reward-refresh` **nicht** deployen oder Cron aktivieren: Dieser Worker ist weiterhin nur Staging/Diagnose.
