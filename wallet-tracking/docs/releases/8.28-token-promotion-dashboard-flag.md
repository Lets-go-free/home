# WalletTracking 8.28 · Token-Promotion und Dashboard-Flag

Erstellt: 13.11.2026 10:19:50 CET · Build 20261113-101950

## Änderung

- Admin-Promotion eines sicheren Tokens in `predefined_tokens` fragt unmittelbar nach dem Upsert per bestehendem `token-metadata`-Resolver die technische Token-Metadaten ab und lädt die persistierten Stammdaten neu.
- Wenn der Provider keine verifizierten Dezimalstellen liefert, bleibt der Token übernommen, aber die UI meldet, dass die Metadaten offen sind. Fehlende Einheiten werden nicht erraten.
- Das Flag «In der Dashboard-Kursübersicht anzeigen» ist nicht mehr auf Projekt-Token beschränkt. Die Einstellung wird für alle vordefinierten Token gespeichert und beim Rendering angewendet.
- Projektbeteiligungsprüfung, Bestandsgrenze, «immer anzeigen», Kursbestimmung und gespeicherte Werte bleiben unverändert.

## Installation / Live-Test

Nur Browser-Dateien aktualisieren; kein SQL und kein Edge-Deployment. Test mit Ethereum XAUD und DSYNC: «Technische Metadaten ergänzen (Admin)» für bereits zuvor promotete Token ausführen, dann Dezimalstellen und Persistenz des Kursflags prüfen. Ein Preis kann weiterhin fehlen, wenn keine gültige Quelle vorliegt.

## Status

Lokale statische Prüfungen erfolgreich; echte Metadatenauflösung und UI-Verhalten in Supabase noch nicht live bestätigt. Danach Bitcoin-Fallback-Livetest und Bestandsverlauf fortsetzen.
