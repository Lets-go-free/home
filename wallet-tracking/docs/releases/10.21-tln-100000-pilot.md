# 10.21 · TLN/VOW-Pilot mit 100’000 Blöcken

Der Abschlussaudit 10.20 war PASS. 30 von 30 Pilot-Scans wurden gespeichert. 1’290’133 Bruttoblöcke, zwei Transferseiten pro Scan, null Rohdatenzeilen. Der Rückfall auf 25’000 wurde live bestätigt. Der lesende 100’000er-Test 16583 war vollständig. Die ersten beiden Versuche lieferten HTTP 503 in der Vorprüfung.

## Ausführung

`supabase/migrations/20261127164256_tln_vow_100000_pilot_1021.sql` einmal im Supabase SQL Editor ausführen.
Der nächste volle Minutenstart beginnt die Pilotphase. Nach 30 vorgesehenen Minutenstarts greift automatisch der Rückfall auf 25’000.
Job 15 protokolliert die Antworten. Die Migration erweitert die zulässigen Blockgrössen im Audit und ändert den Befehl von Job 14.

## Abschlussaudit

Frühestens zwei Minuten nach der in der SQL-Meldung ausgewiesenen Rückfallzeit abfragen.
Bei `PASS` sind alle 30 Pilot-Requests vollständig gespeichert, ohne Fehler oder Schreibkonflikte, und der Rückfall ist live bestätigt.
Adaptive Reduktionen und kleinere Fenster gesondert auswerten. Die Bruttoblockzahl enthält Überlappungen.
Über die Eignung der Blockgrösse erst nach dem Audit entscheiden. Die Ursache der Null-Rohdatenzeilen und die historische Vollständigkeit bleiben offen.

```sql
WITH pilot_config AS (
    SELECT max(pilot_end) AS pilot_end
    FROM wallettracking_internal.tln_raw_scan_audit
    WHERE requested_blocks = 100000
),

audit AS (
    SELECT a.*
    FROM wallettracking_internal.tln_raw_scan_audit a
    CROSS JOIN pilot_config p
    WHERE a.pilot_end = p.pilot_end
      AND (
          (
              a.requested_blocks = 100000
              AND a.queued_at >=
                  p.pilot_end - interval '30 minutes'
              AND a.queued_at < p.pilot_end
          )
          OR
          (
              a.requested_blocks = 25000
              AND a.queued_at >= p.pilot_end
          )
      )
),

stats AS (
    SELECT
        requested_blocks,
        count(*) AS requests,

        count(*) FILTER (
            WHERE outcome = 'saved'
        ) AS gespeichert,

        count(*) FILTER (
            WHERE outcome = 'pending'
        ) AS ausstehend,

        count(*) FILTER (
            WHERE outcome NOT IN ('saved', 'pending')
        ) AS fehler,

        count(*) FILTER (
            WHERE outcome = 'saved'
              AND (
                  incoming_complete IS DISTINCT FROM true
                  OR outgoing_complete IS DISTINCT FROM true
                  OR persisted IS DISTINCT FROM true
                  OR ok IS DISTINCT FROM true
                  OR executed IS DISTINCT FROM true
                  OR dry_run IS DISTINCT FROM false
                  OR reported_requested_blocks
                     IS DISTINCT FROM requested_blocks
              )
        ) AS unvollstaendig,

        count(*) FILTER (
            WHERE outcome = 'saved'
              AND (
                  scanned_blocks IS NULL
                  OR from_block IS NULL
                  OR to_block IS NULL
                  OR scanned_blocks <= 0
                  OR scanned_blocks > requested_blocks
                  OR scanned_blocks <>
                      to_block - from_block + 1
              )
        ) AS inkonsistente_blockbereiche,

        count(*) FILTER (
            WHERE outcome = 'saved'
              AND scanned_blocks = requested_blocks
        ) AS volle_chunks,

        count(*) FILTER (
            WHERE outcome = 'saved'
              AND scanned_blocks < requested_blocks
        ) AS kleinere_chunks,

        coalesce(sum(scanned_blocks) FILTER (
            WHERE outcome = 'saved'
        ), 0) AS bloecke_brutto,

        round(avg(scanned_blocks) FILTER (
            WHERE outcome = 'saved'
        ), 2) AS bloecke_pro_scan,

        round(avg(pagination_pages) FILTER (
            WHERE outcome = 'saved'
        ), 2) AS pagination_pro_scan,

        count(*) FILTER (
            WHERE adaptive_reduced IS TRUE
        ) AS adaptive_reduktionen,

        coalesce(sum(conflict_retries), 0)
            AS schreibkonflikte,

        coalesce(sum(raw_rows) FILTER (
            WHERE outcome = 'saved'
        ), 0) AS rohdaten

    FROM audit
    GROUP BY requested_blocks
)

SELECT jsonb_pretty(
    jsonb_build_object(
        'version', '10.21',

        'zeit_ch',
            now() AT TIME ZONE 'Europe/Zurich',

        'pilot_ende_ch',
            p.pilot_end AT TIME ZONE 'Europe/Zurich',

        'pilot_beendet',
            now() >= p.pilot_end,

        'scan_statistik', (
            SELECT jsonb_agg(
                to_jsonb(s)
                ORDER BY requested_blocks DESC
            )
            FROM stats s
        ),

        'fallback_25000_live_bestaetigt',
            EXISTS (
                SELECT 1
                FROM stats
                WHERE requested_blocks = 25000
                  AND gespeichert > 0
                  AND unvollstaendig = 0
                  AND inkonsistente_blockbereiche = 0
            ),

        'fehlerdetails', (
            SELECT coalesce(
                jsonb_agg(
                    jsonb_build_object(
                        'request_id', request_id,
                        'zeit_ch', queued_at
                            AT TIME ZONE 'Europe/Zurich',
                        'blockgroesse', requested_blocks,
                        'status', outcome,
                        'http_status', http_status,
                        'fehlerkategorie', error_category
                    )
                    ORDER BY queued_at
                ),
                '[]'::jsonb
            )
            FROM audit
            WHERE outcome NOT IN ('saved', 'pending')
        ),

        'audit_status',
            CASE
                WHEN p.pilot_end IS NULL
                    THEN 'PILOT_NOT_FOUND'
                WHEN now() < p.pilot_end
                    THEN 'PILOT_RUNNING'
                WHEN NOT EXISTS (
                    SELECT 1 FROM stats
                    WHERE requested_blocks = 100000
                      AND requests = 30
                      AND gespeichert = 30
                      AND fehler = 0
                      AND ausstehend = 0
                      AND unvollstaendig = 0
                      AND inkonsistente_blockbereiche = 0
                      AND schreibkonflikte = 0
                )
                    THEN 'PILOT_REVIEW_REQUIRED'
                WHEN NOT EXISTS (
                    SELECT 1 FROM stats
                    WHERE requested_blocks = 25000
                      AND gespeichert > 0
                      AND unvollstaendig = 0
                      AND inkonsistente_blockbereiche = 0
                )
                    THEN 'FALLBACK_NOT_VERIFIED'
                ELSE 'PASS'
            END
    )
) AS tln_abschlussaudit_1021

FROM pilot_config p;
```
