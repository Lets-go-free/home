# 9.60 – Historische Bonus-/Referral-Evidence

Build: 20261122-145625 (22.11.2026 14:56:25 CET).

## Zweck

Die seit 9.59 aktiven 5-Minuten-Jobs liefern mangels neuer Belege aktuell 0 Bonus- und 0 Referral-Kandidaten. Der neue Modus `historical-bonus-referral-evidence` wertet ausschliesslich bereits gespeicherte, im manuellen Browser-Discovery-Prozess belegte Reward-Zeilen erneut aus. Bonus: gemeinsame `manualBonusEvidenceForClaim`. Referral: gemeinsame `knownClaimMethodIntent` für explizite Referral-Selectoren. Keine alternative Heuristik.

Die Ausgabe enthält anonymisierte Zahlen je Snapshot und in der Gesamtsumme. `otherProvenRows` bedeutet **nicht**, dass diese Zeilen keine Rewards sind; die breitere Browser-Step-5-Referenz-/Pfadlogik bleibt hier ausdrücklich ungeprüft. Das Ergebnis beweist weder historische Vollständigkeit noch korrekte Zuordnung unbekannter Payouts.

## Installation und Test

Nur Edge Function `tln-vow-reward-refresh` neu deployen. Danach authentifizierter POST-Body:

```json
{"mode":"historical-bonus-referral-evidence"}
```

Antwort: `summary`, `details`, keine Identitäten, `persisted:false`. Es gibt keine SQL-Migration. Bestehende 5-Minuten-Jobs unverändert aktiv, Daily-Direct-Claim-Cron unverändert inaktiv.
