# 9.49 – TLN/VOW gemeinsame Step-2-Unstake-Zuordnung

Build: 20261122-103126 (22.11.2026, 10:31:26 CET).

Der Browser hat eine sekundäre Zuordnungsregel für erfolgreiche Unstake-Calls: nur **ein** noch offenes Lot desselben Staking-/Entry-Contracts und nicht vor der Stake-Zeit. Diese Regel wird nun gemeinsam von Browser und Server verwendet. Der Server prüft zusätzlich Receipt-Sender, Registry und Stake-Blockchronologie; das Ergebnis `manualPositionEvidence.uniqueUnstakeLotIndex` wird im vorhandenen technischen Receipt-Cache gespeichert.

Parallele offene Lots bleiben mehrdeutig. Die stärkere primäre Browser-Zuordnung über exakte Principal-Rückgabe bleibt unberührt. Es werden keine bestehenden Lots geschlossen, keine neuen Lots angelegt, keine Lockdauer extrapoliert, keine Rewards/Claims verändert und keine Cronjobs umgestellt. Die vollständige autonome Step-2-/3-Verarbeitung bleibt ein offener Entwicklungspunkt.

Installation: übliches ZIP; danach `tln-vow-reward-refresh` mit dem enthaltenen `index.ts` erneut deployen. Keine SQL-Migration. Lokaler Test: `node tests/tln-vow-shared-unstake-lifecycle-949.test.mjs`.
