# Release-Dokumentation

Der aktuelle Programmstand, Installation und aktuelle Tests stehen in [README.md](../../README.md) und in Admin → Dokumentation. [CHANGELOG.md](CHANGELOG.md) ist die chronologische Kurzfassung der Änderungen.

README-7.xx.md sind unveränderte historische Detailberichte: damalige Installationsschritte und offene Punkte können heute überholt sein. Keine SQL-Anleitung aus einem alten Bericht ohne Abgleich mit der aktuellen Baseline ausführen.

Release-Berichte 7.33 bis 7.44 liegen hier. Zum Entfernen alter Root-Kopien nach Update 7.55 im lokalen wallet-tracking-Verzeichnis _wt-docs-cleanup.command ausführen. Der Helfer prüft Inhalte, bewahrt abweichende Dateien und ist wiederholbar. SQL-Anleitungen bleiben neben den SQL-Dateien; Migrationen werden nicht gelöscht.
