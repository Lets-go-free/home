# WalletTracking 8.01 – frühe DAO-Reward-Sonderfälle

Vier DAO1/APTM-Claims mit positiven Mengen (Blöcke 60'731, 72'665, 81'698, 81'700) liegen vor dem ersten exakten zentralen Preisanker, Block 88'356. Das Audit-Feld `audit_classification` wird dauerhaft auf `unpriced_before_exact_anchor` gesetzt. Das ist eine Bewertungsausnahme, kein Beleg für eine Auszahlungsverifizierung. `canonical_existing_verified` bleibt unangetastet.

Die Migration prüft Zahl und Zustand der vier Transaktionen und ist wiederholbar. Bei einem unerwarteten Befund wird zurückgerollt. Es erfolgt keine Änderung am kanonischen Preis, Reward, NFT, Wallet oder Scan-Status.

Drei Null-Reward-Transaktionen (Blöcke 403'915, 10'791'488, 11'254'937) enthalten in der aktuellen Datenbank keine erfassten Asset-Flows. Das ist kein vollständiger Negativnachweis on-chain. Diese Transaktionen bleiben offen für Belegprüfung.
